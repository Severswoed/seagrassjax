# Security Policy

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues or discussions.

Use GitHub's **Report a vulnerability** option in this repository's **Security** tab to send a private vulnerability report. If private vulnerability reporting is unavailable, contact the repository owner privately through GitHub and ask for a secure channel before sharing vulnerability details.

There are no production releases yet. Security fixes will be handled on the default branch and noted in release information if releases are created.

## Scope

This policy covers the website source and its GitHub Pages deployment configuration in this repository. The site is static; estimate submissions are processed by the separately operated Web3Forms service, which has its own security and disclosure policies.
